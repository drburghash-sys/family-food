# سعرات العائلة — النسخة الشخصية V6

هذه النسخة أعيد تصميمها لتكون **شخصًا واحدًا لكل جوال** بدل إدارة عدة أفراد داخل جهاز واحد.

## التغييرات الرئيسية
- لا توجد أسماء وجبات ولا مكتبة أكلات.
- إضافة السعرات تكون برقم فقط.
- اختيار السعرات من **1 إلى 2000** عبر شريط اختيار + إدخال رقمي + أزرار سريعة.
- تسجيل الماء بأزرار سريعة أو كمية مخصصة، ويمكن تعديل إجمالي ماء اليوم مباشرة.
- تسجيل وزن اليوم فقط، مع رسم اتجاه الوزن في السجل.
- سجل آخر 14 يومًا للسعرات والماء والوزن.
- إعداد هدف السعرات وهدف الماء مرة واحدة على كل جهاز.
- بيانات كل جهاز مستقلة ومحفوظة محليًا.
- تصدير واستعادة نسخة احتياطية JSON.
- عند وجود بيانات النسخة العائلية القديمة على نفس الجهاز يظهر خيار اختياري لنقل شخص واحد فقط (الأهداف والوزن الحالي) من دون حذف البيانات القديمة.
- PWA قابلة للتثبيت على Android وiPhone من المتصفح وتعمل دون اتصال بعد أول تحميل.

## ملاحظة iPhone / Android
APK خاص بأندرويد فقط. هذه النسخة PWA تعمل على النظامين من نفس رابط GitHub Pages:
- Android: تثبيت التطبيق من قائمة المتصفح.
- iPhone: Safari ← مشاركة ← إضافة إلى الشاشة الرئيسية.

يمكن لاحقًا تغليف نفس المشروع كتطبيق Android APK عبر Capacitor، ولـ iPhone يلزم مسار iOS (IPA/TestFlight/App Store) وليس APK.
