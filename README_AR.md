# عائلتي الصحية — PWA V3

## ما تم تصحيحه
- الأحد إلى الخميس: وجبتان رئيسيتان جاهزتان لكل يوم.
- الأسابيع الأربعة تحتوي خططًا مختلفة، وكل وجبة تقارب 360–390 سعرة.
- الجمعة والسبت يومان مفتوحان.
- لكل وجبة رئيسية: **تبديل** و**حذف**.
- يمكن إضافة وجبة رئيسية جديدة في الأيام الخمسة الأولى.
- يمكن حذف الأكلات الشخصية.
- بعد الإضافة أو الحذف أو التبديل يظهر **تراجع** لمدة 7 ثوانٍ.
- وجبات كل شخص الإضافية تبقى منفصلة.
- عند التحديث من V2 تُحفظ الإضافات الشخصية وتُحدّث الوجبات الرئيسية إلى الخطة الجديدة.

ارفع الملفات إلى GitHub Pages كالمعتاد، ثم حدّث الصفحة في Chrome.


## تحديث V4 — iPhone والجوال
- الحفاظ على نفس نظام التطبيق وبياناته المحلية.
- الواجهة أصبحت محسنة للوضع الطولي على الجوال.
- دعم Safe Area لأجهزة iPhone ذات النتوء/الجزيرة الديناميكية.
- منع تكبير Safari التلقائي عند إدخال البيانات.
- اتجاه التطبيق Portrait في ملف manifest.
- استخدام الأيقونة الجديدة كأيقونة PWA وApple Touch Icon.
- إضافة حساب الفرق: الاحتياج اليومي − المكتسب، مع توضيح المتبقي أو مقدار تجاوز الاحتياج.
- رفع إصدار Service Worker لإجبار GitHub Pages على تحديث الملفات القديمة.


## تحديث V5 — الماء وأقسام الشخص
- إضافة احتياج الماء اليومي، الماء المكتسب، والفرق بينهما.
- شاشة كل شخص أصبحت قائمة أقسام؛ كل قسم يفتح في شاشة مستقلة.
- الخميس والجمعة فقط يومان مفتوحان ولا توجد فيهما وجبات رئيسية.
- فصل الوجبات الرئيسية عن الأكلات الإضافية، مع احتساب الإضافات ضمن السعرات المكتسبة.
- مخزن الأكلات أصبح موضحًا كمخزن مشترك لجميع أفراد العائلة.
- زر «اسأل ChatGPT» يفتح ChatGPT بسؤال جاهز لتقدير سعرات الوجبة، ثم يُدخل المستخدم الرقم الناتج في التطبيق.
- حساب السعرات أصبح بنسبة خفض مئوية يحددها المستخدم. لمن دون 18 سنة لا يطبق الخفض تلقائيًا إلا عند تحديد أن الهدف معتمد من مختص.
- رفع إصدار Service Worker لتحديث GitHub Pages دون بقاء نسخة الكاش القديمة.
